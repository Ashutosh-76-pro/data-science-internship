# Sprint 3 demo datasets

The Sprint 3 branch uses a **synthetic 92-company Nifty-100-style demo universe** so the screener, peer engine, Excel exports, radar charts and unit tests are reproducible without claiming that generated values are live or authoritative market data.

`n100_financials.csv` contains one latest-year row per company. `peer_groups.xlsx` assigns every company to exactly one of the 11 required peer groups and marks one benchmark company per group. Replace these demo inputs with the upstream Sprint 1/2 validated datasets when available.
