**Week 1:** Analytics fundamentals, Excel, SQL, Python, statistics and data cleaning.

## Slide 4 — Analytics Lifecycle
Business problem → data sources → profiling → cleaning → analysis → visualization → insight → recommendation → decision.

## Slide 5 — Dataset
Synthetic retail transaction dataset containing:
- Transaction/date
- Region/segment
- Category/product
- Units, price, cost
- Discount and return status

## Slide 6 — Data Quality
Identified training issues:
- Missing discount value
- Duplicate transaction ID
- Need for type and text standardization

Treatment was made explicit before KPI analysis.

## Slide 7 — KPIs
Core measures:
- Gross Sales
- Net Sales
- Profit
- Margin %
- Return Rate
- Regional/category sales
- Monthly trend

## Slide 8 — Python & EDA
Pandas workflow:
- Profile structure and missing values
- Remove duplicate transaction IDs
- Create sales/profit fields
- Segment performance
- Generate monthly and regional charts

## Slide 9 — SQL
Practice covers:
- SELECT, WHERE, GROUP BY, HAVING
- Aggregations and CASE
- CTEs
- LAG and window functions
- Ranking
- Data-quality checks

## Slide 10 — Power BI & DAX
Dashboard layout:
1. KPI cards
2. Monthly sales trend
3. Regional performance
4. Category performance
5. Return-rate analysis
6. Slicers for date/region/category

Example DAX measures:
`Total Sales`, `Total Profit`, `Profit Margin %`, `Return Rate %`.

## Slide 11 — Business Questions & Insights
- What happened?
- What changed?
- Why did it change?
- Which region/category performed best?
- Where should management investigate?

Insights should be tied to evidence, not assumptions.
