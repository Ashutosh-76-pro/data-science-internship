# Data Analyst Prerequisite — Project Report

**Candidate:** Ashutosh Yadav  
**Repository:** `Ashutosh-76-pro/data-science-internship`

## 1. Objective
Build project readiness across Excel, SQL, Python/Pandas, statistics, data cleaning, EDA, Power BI, DAX, KPI analysis and business storytelling.

## 2. Business Problem
Analyze synthetic retail sales data to understand sales performance, profitability, returns, regional performance, category performance and monthly trends.

## 3. Analytical Workflow
Business question → data understanding → profiling → cleaning → transformation → KPI calculation → EDA → segmentation → visualization → insight generation → recommendations.

## 4. Data Quality Work
The training dataset includes a missing discount value and a duplicate transaction ID. The Python workflow documents and applies explicit treatments for these issues before analysis.

## 5. Core KPIs
- Gross Sales
- Net Sales
- Profit
- Profit Margin
- Return Rate
- Sales by Region
- Sales by Category
- Monthly Net Sales

## 6. Tools
Excel, SQL, PostgreSQL-compatible queries, Python, Pandas, NumPy, Matplotlib and Power BI/DAX concepts.

## 7. Business Questions
1. What happened to sales over time?
2. Which regions performed best?
3. Which categories contributed most sales?
4. Which products/segments require attention?
5. How large is the return problem?
6. Where are low-margin opportunities or risks?

## 8. Recommendations Framework
Use high-performing regions/categories as benchmarks, investigate low-margin products, monitor return-heavy segments, and track monthly trends with an executive dashboard.

## 9. Assessment Readiness
The repository includes practical SQL, Python/EDA, Excel and Power BI/DAX practice plus a mock prerequisite assessment. Successful project readiness should be demonstrated through independent execution, interpretation and communication rather than definition memorization.
