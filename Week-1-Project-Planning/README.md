# Week 1 — Data Science Project Planning & Strategy Design

## Project
**Customer Churn Prediction — Python-Based Data Science Strategy**

### Objective
Design an end-to-end data science process for a hypothetical customer churn prediction problem without requiring a dataset or actual model execution.

### Scope
- Problem definition and business motivation
- Data requirements and collection strategy
- Data cleaning and preprocessing
- Exploratory data analysis
- Feature engineering
- Candidate model selection
- Evaluation and validation strategy
- Expected outcomes, risks and mitigation
- 34-hour project timeline

### Coding requirement
**No actual coding/execution is required for the official Week 1 assignment.** Python is the planned implementation language for later technical stages. The repository's optional `src/churn_pipeline.py` uses synthetic data only to demonstrate how the proposed workflow could be implemented.

### Planned tools
Python, pandas, NumPy, Matplotlib, Seaborn, scikit-learn and Jupyter Notebook.
